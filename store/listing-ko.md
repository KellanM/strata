## Description (4000)

```
모든 돌은 무언가를 품고 있어요.

Strata는 그것을 찾아내는 조용한 퍼즐이에요. 스테이지마다 돌덩이 하나에 모양 하나가 숨어 있어요. 랜턴, 웅크려 잠든 여우, 등대, 아직 불을 뿜지 못하는 아기 용. 돌의 세 면에 적힌 숫자는 각 줄에 모양의 큐브가 몇 개 있는지 알려 줘요. 숫자를 읽고 모양에 속하지 않는 큐브를 끌로 깎아 내면, 모양이 천천히 드러나요.

말하자면 3차원 네모로직(노노그램)이에요. 돌을 손안에서 돌려 보고, 층을 벗겨 안을 들여다보고, 한 줄씩 풀어 모양만 남겨 보세요.

■ 15개 세계를 지나는 여행
15개 세계에 200개의 돌. '첫 빛'과 '이끼 정원'에서 '등불 축제', '심해', '별 내리는 밤'까지. 세계마다 고유한 빛과 색이 있고, 찾아낸 모양은 작은 조각상이 되어 지도 위에 놓여요. 세계마다 보석을 모은 사람을 위한 보너스 돌(사당)이 하나씩 기다려요.

■ 쉽게 배우기
짧은 레슨 12개로 플레이하면서 모두 배울 수 있어요. 숫자 읽는 법, 끌 쓰는 법, 남길 큐브를 표시하는 법. 여행이 이어질수록 돌은 커지고 단서는 줄지만, 규칙은 변하지 않아요. 막히면 잠시 기다려 보세요. 풀 수 있는 줄이 은은하게 빛나요.

■ 내 속도대로
작은 시계가 올라가지만 시간 제한은 없고, 시간 때문에 보석이 줄지도 않아요. 실수는 되돌릴 수 있어요. 보석은 빠른 손이 아니라 차분한 손에게 돌아가요.

■ 고요함을 위한 설계
• 완전히 오프라인으로 플레이
• 광고 없음, 추적 없음
• 계정도 로그인도 필요 없음
• 앱 내 구입 없음
• 진행 상황은 내 기기에만 저장

조용한 몇 분을 찾아 돌 하나를 집어 들고, 그 안에 무엇이 있었는지 확인해 보세요.
```

## Keywords (100 bytes)

```
노노그램,네모네모,로직퍼즐,그림퍼즐,입체,큐브,힐링,두뇌,숫자,오프라인
```

(99 / 100 bytes)

Comma-separated with no spaces. Leaves out words already in the name or subtitle (Strata, 돌, 퍼즐, 3D, 네모로직, 잔잔한), which Apple indexes anyway. 피크로스 (Picross) is a Nintendo trademark and is not used. 노노그램 is the international name; 네모네모 catches 네모네모 로직 searches, the other common Korean name; 로직퍼즐 and 그림퍼즐 are how Korean stores file the genre. 입체 catches 입체 퍼즐 searches; 힐링 and 두뇌 stand in for the English "relaxing" and "brain".

## Notes for the reviewer

- **Stars → 보석.** The English description says "stars" ("earn their stars", "never costs you a star"); the game itself calls them gems (◆), so this uses 보석, the game's word. Same claim, one name.
- **"A bonus stone"** is written 보너스 돌(사당) so the store word matches the map's 사당.
- **Chapter names** in the description are the in-game ones (첫 빛, 이끼 정원, 등불 축제, 심해, 별 내리는 밤).
- **"Chapters" → 세계,** as in the Japanese listing and the game's own "Locked world" (잠긴 세계).
