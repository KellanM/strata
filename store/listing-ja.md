```
どの石にも、何かがしまわれています。

Strataは、それを見つけるための静かなパズルです。ステージはどれも石のかたまりで、中にかたちがひとつ隠れています。ランタン、丸くなって眠る狐、灯台、まだ火を吹けないドラゴンの子。石の3つの面に並ぶ数字は、かたちのキューブがそれぞれの列にいくつあるかを示します。数字を読み、かたちに含まれないキューブをノミで削っていくと、かたちが少しずつ姿を現します。

いわば、3次元のノノグラム（お絵かきロジック）です。石を手の中で回し、層をはがして中をのぞき、列をひとつずつ解いて、最後にかたちだけを残しましょう。

■ 15の世界をめぐる旅
15の世界に、194の石。「はじまりの光」や「苔の庭」から、「提灯まつり」「深海」「星降る夜」まで。世界ごとに光と色があり、見つけたかたちは小さな彫刻として地図に並んでいきます。どの世界にも、宝石を集めた人のためのボーナスの石（祠）がひとつ待っています。

12の短いレッスンで、遊びながらすべてを覚えられます。数字の読み方、ノミの使い方、残したいキューブに印をつける方法。旅が進むにつれて石は大きく、手がかりは少なくなりますが、ルールはずっと変わりません。行き詰まったら少し待ってください。手を進められる列が、そっと光ります。

小さな時計は進みますが、時間切れはなく、時間で宝石が減ることもありません。ミスは取り消せます。宝石が報いるのは、速い手ではなく、落ち着いた手です。

• アカウント登録・サインインは不要
• アプリ内課金なし
• 進行状況はお使いの端末の中にだけ保存されます
```

## Keywords (100 bytes)

(96 / 100 bytes)

Comma-separated with no spaces. Leaves out words already in the name or subtitle (Strata, 石, パズル, 3D, ゆったり), which Apple indexes anyway. ピクロス is a Nintendo trademark and is not used. お絵かきロジック and イラストロジック are the common Japanese names for nonograms; 立体 catches 立体パズル and 立体ロジック searches; 脳トレ and 癒し stand in for the English "brain" and "relaxing".

## Notes for the reviewer

- **Stars → 宝石.** The English description says "stars" ("earn their stars", "never costs you a star"); the game itself calls them gems (◆), so this uses 宝石, the game's word. Same claim, one name.
- **"A bonus stone"** is written ボーナスの石（祠） so the store word matches the map's 祠.
- **Chapter names** in the description are the in-game ones (はじまりの光, 苔の庭, 提灯まつり, 深海, 星降る夜).
