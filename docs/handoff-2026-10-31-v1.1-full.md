## 1. Build

1. **Xcode 27.1 and the iOS 27.1 SDK.** This is the only opt-in for the Duo: there is no Info.plist key, and without it the Duo shows the app letterboxed and gives no badge. First check that Capacitor 8 builds cleanly with it.
2. `git pull`, `npm ci`, then `npm run build:app`, which runs `tools/build.mjs --app`, `npx cap sync ios` and `tools/ios-configure.mjs`.
   - `cap sync` picks up the new plugin **`@capacitor-community/in-app-review` 8.x**, used for the rating sheet.
   - **`ios-configure.mjs` now also:**
     - checks for the launch screen, which the 27.1 SDK requires;
     - removes `UIRequiresFullScreen`, so the system can resize the window;
     - declares **`CFBundleLocalizations`** for all ten (en, ja, zh-Hans, zh-Hant, ko, de, fr, es, pt-BR, ru). Without it, iOS runs the web view in English even on a Japanese iPhone.
   - `TARGETED_DEVICE_FAMILY` stays **1** (iPhone only; the Duo is an iPhone). iPad is v1.3, and going universal can't be undone.
3. **Game Center** (the Daily Stone's leaderboard and Challenges): add the local plugin by hand, following `docs/game-center-handoff.md` "Steps on the Mac":
   1. Copy `ios-config/GameCenter/StrataGameCenterPlugin.swift` and `MainViewController.swift` into the App target.
   2. Set `Main.storyboard`'s view controller class to `MainViewController`.
   3. Add the Game Center capability.
   4. Test on a sandbox account.

   The Swift for the Challenge sheet and the activity listener was written against Apple's docs and has **never been compiled**, so check it against the iOS 26/27 SDK. If it won't build in reasonable time, ship 1.1 without it. The game's JavaScript treats a missing plugin as a quiet no-op: the daily still works and shares, with no Challenge ring. Tell Kellan which way it went.
4. Archive and upload build 8 with the API key, as before. **Never upload a profiling or autobench build.**

## 2. Check on the simulator, then on devices if you can

- **Duo:** the "Device checks" list in `docs/handoff-2026-10-31-v1.1-duo.md`:
  - fold and unfold mid-level, on the map, in a lesson and on the result;
  - the system's resize snap;
  - Split View at its narrowest;
  - the crease on a real Duo, where the block sits;
  - frame rate on the inner screen.
- **Languages:** set the simulator to each of the ten in turn (at least 日本語, 繁體中文, 한국어, Deutsch and Русский). The game should open in that language, with no English left on the title, the lessons, the map, a level, the result or Settings.
- **Larger text:**
  - With iOS Settings › Display › Text Size raised, the game's Larger text should be on at first launch.
  - After you change it in the game, the game's choice sticks.
  - Not yet verified on a device: whether WKWebView reports the iOS text size (`-apple-system-body`). Report what you see.
- **Rating sheet:** close two worlds on a test save. The sheet may not appear in TestFlight or the simulator; Apple limits it there. Just confirm nothing breaks.
- **Daily Stone:**
  - Today's ring on the map (after the lessons): solve it, then Share.
  - With Game Center, the score goes to `strata.daily.score`, and the Challenge ring opens Apple's sheet.
